Archivio personale

A private desktop tool that keeps an organized copy of its owner's own documents in a folder of the owner's Google Drive.

What it does

The tool runs only on its owner's computer. When the owner's documents change, it creates folders in the owner's Google Drive, uploads the new versions, keeps the previous versions in a separate folder and adds shortcuts to the folders that are currently in use. It is not offered to other people.

Access to Google Drive

The tool asks Google only for the drive.file permission: it can see and change only the files and folders it has created itself. It cannot read any other file in the owner's Drive. The owner can remove the permission at any time from myaccount.google.com/permissions.

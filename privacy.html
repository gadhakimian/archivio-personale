Privacy policy

Archivio personale · last updated 11 October 2026

Who uses the tool

Archivio personale is a private tool used only by its owner, on the owner's own computer, to store copies of the owner's own documents in the owner's Google Drive. It has no other users.

Google user data the tool accesses

Only the files and folders that the tool itself creates in the owner's Google Drive, through Google's drive.file permission. The tool does not see, read or change any other file in the Drive.

How the data is used

The tool creates folders, uploads and updates the owner's documents, keeps earlier versions in a separate folder, creates shortcuts and moves files to the trash when the owner deletes a document. It does nothing else with Google data.

Storage and sharing

The authorization that Google issues is stored encrypted on the owner's computer. No Google user data is sold, shared with third parties, used for advertising or analytics, or used to train artificial intelligence models. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke the tool's access at any time from myaccount.google.com/permissions. Files already in the Drive stay there until the owner deletes them.
